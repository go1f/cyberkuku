# CyberKuku

CyberKuku 是一款可以换形象、装插件的 Mac 桌宠应用。默认形象是一只坐在椅子上的小灰猫。你可以把它挪到手边，也可以把它拖到屏幕边缘收起来，等鼠标靠近时再探出头来。

## 让它帮你留意坐姿

在菜单栏打开「设置 → 拓展」，导入并启用「同学请注意坐姿！」。第一次使用时，看向平常工作的屏幕，校准自己放松时的坐姿。之后，如果你持续歪头或耸起一边肩膀，桌宠就会用气泡提醒你「头向左扶正」或「双肩放平」。摄像头画面只在本机处理。

## 安装

适用于搭载 Apple 芯片、运行 macOS 14 或更高版本的 Mac。下载 DMG，打开后将 CyberKuku 拖入「应用程序」即可。[下载最新版](https://github.com/go1f/cyberkuku/releases/latest)
