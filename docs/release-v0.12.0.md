# KukuSeat v0.12.0

- 拖到左右工作区边缘并松手后收纳。收纳位置跨启动保存；单击展开，双击打开或聚焦监控窗口，可拖回桌面。展开态仍保留单击静默 30 秒。
- 收纳后在原图“小手搭边、回头偷看、耳尖藏边”三态中洗牌轮换，每次停留 30–60 秒，每轮各一次，相邻不重复；切换先退回再探出，总计约 0.85 秒。
- 边缘入口固定为 44×44pt，造型变化不移动热区。悬停、按下、拖动、暂停、隐藏及全屏抑制会暂停轮换；恢复重新计时，不补播积压动画。
- 小猫进入显示器右三分之一区域后转身，背部靠右。采用 180ms 的原图缩放翻转帧，临界位置有 6pt 滞回缓冲；图像朝向与摄像头镜像设置分开。
- 按显示器读取可见窗口几何，检测覆盖整屏的窗口并隐藏对应屏幕的小猫和气泡；同时使用原生非全屏窗口行为避让全屏空间。检测不读取窗口标题、画面或请求辅助功能权限。全屏恢复后保留展开／收纳意图，等待新的监测显示更新。
- 系统减少动态效果时关闭转身、收纳过渡和循环换造型。所有外观变化不重置坐姿异常、恢复或静默计时。

全屏抑制采用窗口覆盖几何判断；真实多屏全屏切换、边缘拖拽和最终手感仍需人工核验。
