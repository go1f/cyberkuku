# CyberKuku 1.0 架构

`CyberKukuApp` 启动常驻宿主 `CompanionHost`。宿主管理桌面形象、设置窗口和应用更新。菜单栏可以切换小灰猫或纸船，切换时保留桌面位置。

## 设置与菜单

| 入口 | 职责 |
| --- | --- |
| 菜单栏「切换形象」 | 立即更换桌面形象并保存选择。 |
| 「注意坐姿」子菜单 | 打开监测、切换画中画、开始或暂停监测，以及直达坐姿设置。 |
| 「设置」及 ⌘, | 打开同一个设置窗口。「伙伴」管理形象，「注意坐姿」管理插件启停、校准、提醒与预览。 |
| 「应用更新」 | 打开宿主更新窗口。 |

监测窗口的齿轮与插件的「坐姿设置」使用宿主提供的同一路由。插件停用后，设置窗口仍可用，坐姿页回到启用状态。识别参数采用内置值，提醒强度有三档。手口习惯可展开，个人动作示范在独立面板中采集。

## 生命周期与提醒

`AppearancePlugin` 常驻，`PosturePlugin` 按设置启停。启用只注册入口；开始监测才启动摄像头。自动恢复必须满足已启用、允许恢复、已有校准与摄像头已授权。停用会停止采集、关闭监测与画中画窗口并撤回所属提醒。

坐姿插件经 `BubbleOutput` 发布短句和状态快照。`BubbleHub` 给每次启用分配独立的作用域，隔离同名通道并丢弃失效回调。宿主负责气泡位置、切换动画和 30 秒静音；摄像头画面、校准与口部样本由坐姿模块在本机处理。
