# cyberkuku · 桌面电子伙伴

产品与架构设计稿，基于 KukuSeat v0.12.10。cyberkuku 是暂定展示名。

## 三个时刻

**第一次见面。** 首次安装默认展示小灰猫。主窗口让用户预览形象、试穿后采用。只有进入「能力 → 注意坐姿 → 开始监测」才请求摄像头。

**工作中。** 平时小灰猫安静地坐在桌边。偏离持续到设定阈值后，「注意坐姿」请求宿主显示一句动作提示，例如「头向左扶正」。提示从猫头旁缓缓鼓起，键盘焦点留在工作窗口。短暂回正时保留原句，确认恢复后显示勾，再收起气泡。单击气泡让主动提示安静 30 秒。

**移动伙伴。** 拖动时气泡让路，松手后围绕新位置重新排布。边缘收纳后移近探出，点击留下。真正进入全屏才自动收纳。双击常驻的猫可聚焦已启用的监测窗口；右键可换形象。操作按鼠标位移区分点击与拖动。

## 窗口与菜单

| 入口 | 用户看到什么 | 交互 |
| --- | --- | --- |
| 伙伴 | 暖纸色或深墨色桌面，小灰猫居中 | 试穿后采用新形象，保留桌面位置。已启用「注意坐姿」时可以预览一条提醒，无需采集。 |
| 能力 | 「桌面形象」「注意坐姿」各有独立开关和详情 | 启用坐姿能力只注册入口，开始和暂停采集由插件管理。气泡随宿主提供。 |
| 菜单栏 | 打开伙伴、显示或隐藏形象，以及已启用插件贡献的菜单项 | 「注意坐姿」子菜单含监测窗口、画中画、镜像和暂停。菜单跟踪期间固定行高与顺序。 |
| 设置 ⌘, | 通用、交互、插件设置 | 启动、更新和减少动态效果在通用与交互设置中。校准、检测阈值、镜像在「注意坐姿」详情。 |

桌面气泡使用非激活 NSPanel，尾尖指向形象提供的头部锚点。新提示约 280 毫秒从锚点舒展开，出现后不循环缩放。最多并排两条，待处理的其余项留在所属插件详情；同一条的恢复进度就地更新。屏幕拥挤时优先让文字完整可读。减少动态效果时直接淡入。菜单项、键盘和 VoiceOver 均能到达所有主要动作。关闭最后一个窗口后伙伴可继续工作，退出应用时回收所有资源。

## 宿主和插件如何分工

宿主是一个常驻 macOS 进程，提供插件注册、生命周期、权限调度、命令路由、存储命名空间，以及菜单、窗口、桌面浮层的插槽。业务通过插件接入。安装包签名、更新和失败回退跟随宿主维护，避免更新一半后无法启动。首版采用随应用编译签名的 Swift 模块；用户可以独立启停。外观包只描述资源和锚点。第三方可执行扩展需要独立的隔离方案，首版不加载。

| 模块 | 拥有的数据和行为 | 向其他部分提供 |
| --- | --- | --- |
| 桌面形象 | 选择的外观包、绘制、呼吸、朝向、耳手收纳 | 向宿主提供当前形象的屏幕坐标、朝向和头部锚点。通过宿主桌面插槽取得窗口、当前屏幕与位置 |
| 小灰猫外观包 | 现有 Companion.png 和收纳造型；头部、脚底和拖动锚点，左右镜像规则 | 默认外观。新外观缺少收纳姿态时使用通用边缘把手，可用鼠标或键盘还原 |
| 注意坐姿 | 摄像头、Vision、姿态 worker、校准与口部样本、各通道计时、监测窗口和 PiP | 可执行命令、设置页、有限状态摘要和具有生命周期的提醒；图像、关键点及个人样本留在插件内部 |
| 宿主气泡输出 | 插件作用域内的提示标识、短句、阶段和可选恢复进度。负责合并更新、就近排布、静音和收起 | 通过插件上下文提供单向 BubbleOutput 接口，随宿主可用。由插件决定何时提醒和说什么。 |
| 宿主呈现层 | 入口、窗口焦点、桌面位置、静音期限、插件贡献项的注册与移除 | 没有桌面形象时，提醒通过原有简洁提示框呈现；用户主动隐藏伙伴后，提示遵循其提醒和静音偏好 |

### 一条提醒走过的路径

1. 坐姿插件根据校准和观察质量维护独立计时，达到当前用户阈值后送出提示。身份键由插件 ID 与通道 ID 组成。
2. 宿主保存当前有效提示。开始偏离、恢复待确认、恢复、撤回分别对应创建、更新、结束、移除。每条提示带运行代次及单调递增序号，过期回调直接丢弃。短暂看不清沿用检测引擎的暂停语义，不能冒充恢复。
3. 用户静音只改变呈现。30 秒后从当前有效集合重绘；已经恢复的提示不会重新冒出。切换形象也仅重绘，同一条提醒的累计秒数继续保留。
4. 插件停用时宿主撤回该插件名下全部提示，释放呈现资源。仅隐藏形象时将仍有效的提醒切换为简洁提示框。

### 后续扩展契约

| 接口 | 可实现的约束 |
| --- | --- |
| PluginDescriptor | 稳定 ID、宿主 API 版本范围、能力声明、权限需求、命令和设置入口。宿主启动先读描述；菜单展示无需创建摄像头或姿态 worker。 |
| activate(context) / deactivate() | 每次启用建立一个有所有者的运行作用域。停用先失效代次，取消任务与订阅，再释放设备、清理提示、关闭插件窗口。重复调用安全，启动中取消也走同一路径。 |
| CommandRegistry | 命令有命名空间、类型化参数、是否可用、所需权限和执行结果。菜单和快捷键共同调用。插件之间依赖协议，禁止跨插件持有模型或窗口。 |
| BubbleOutput | 由宿主绑定调用方身份与运行代次。插件调用 upsert(id, text, phase, revision) 创建或更新同一条气泡，调用 dismiss(id, revision) 撤回。宿主校验序号并清理已结束的提示。 |
| PresentationStore | 主线程接受带版本的状态快照，按键合并；窗口只订阅需要的变化。高频视频帧走坐姿内部管线。更换外观从一次快照恢复。 |
| ResourceBroker / SettingsStore | 摄像头租约绑定启用作用域；用户授权由 macOS 执行。偏好按稳定插件 ID 分区、独立版本化。进程内接口约束适用于内置受信代码，不构成第三方安全沙箱。 |

启用意图与运行状态分开存储。坐姿插件可以是已启用但未采集、采集中、手动暂停、系统中断或权限被拒。锁屏只暂挂原先运行的采集；解锁前若已被停用，旧回调不得重启。拒绝授权时保留设置入口，其他插件继续。宿主按依赖拓扑激活，重复 ID、缺少依赖及循环依赖在注册阶段报告到能力详情。渲染、命令或初始化返回错误时撤销受影响插件的贡献；同进程崩溃仍影响整个应用。

## 已接入原生应用

0.13.0 的常规入口由 CompanionHost 负责。AppearancePlugin 和 PosturePlugin 通过 CompanionPlugin 接口注册并独立启停。BubbleHub 为每次启用分配独立的 BubbleOutput，插件按快照发布消息或发出一次性短句。同名通道按插件隔离，停用即撤回，上一轮启用的回调自动失效。桌面形象提供小灰猫与纸船两种选择。以下阶段描述代码拆分方向。

## 从现有 Swift 代码迁移

| 阶段 | 切入位置 | 交付验证 |
| --- | --- | --- |
| 1 · 解开启动 | PostureDiagnosticsApp 当前在启动时构造 DiagnosticModel。先建立宿主、描述注册表和命令路由，把监控模型及 worker 移至坐姿工厂按需创建。DesktopCoordinator 保留 AppKit 生命周期。 | 新装首次打开、试穿、预览提醒均无相机提示和 worker。升级前正在监测的用户按原偏好恢复。 |
| 2 · 分离桌宠 | DesktopPetController.present 当前接收 BubbleMessage；在 ReminderPanelController 边界映射为通用提示。PetPlacement、PetPointerDrag、PetEdgeBehavior 移到桌面模块，提醒计时仍在 PostureCore。 | 禁用坐姿后仍可拖猫和换装；禁用形象后监测和备用提示仍工作；切换外观保持锚点与静音期限。双屏、全屏与最大化延续现有回归检查。 |
| 3 · 更换产品入口 | StatusPanelController 改读宿主快照和命令树。原 MonitorWindowView、PiP 与高级设置由坐姿插件注册；增设伙伴主页、外观预览并接入宿主气泡输出。 | 验证双击聚焦、⌘W、⌘,、被动提醒保留焦点、监测暂停快捷键，以及插件停用时打开的窗口和菜单。 |

第一阶段的验收场景只有一条主线：关闭坐姿能力，再重启应用、移动小灰猫并更换形象。整个过程没有相机活动，也没有坐姿插件留下的菜单、窗口或气泡。
