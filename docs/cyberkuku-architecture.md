# CyberKuku 架构

宿主管理桌面呈现、设置窗口和应用更新。应用在组合入口向 `CompanionHost` 传入插件注册表。宿主按注册项显示公开能力与配置入口，坐姿检测及其设置由 `PostureExtension` 提供。

## 插件商店

商店从 GitHub 最新 Release 读取 `extensions.json`。仓库内的清单源文件为 `extensions/catalog.json`，每条记录声明插件 ID 和 API 版本。本地注册表提供标题、说明、图标及运行工厂。「导入」将匹配的插件加入已安装列表，之后可离线启停。当前商店为随应用签名的原生实现提供分发入口，清单只引用已注册模块。第三方代码加载与独立插件更新需要后续协议。

「同学请注意坐姿！」的本地注册被集中在 `PostureExtension.swift`。它接收宿主分配的气泡作用域和一个打开本插件设置的回调。应用更新器由宿主持有。

## 设置和插件生命周期

设置使用 macOS 侧栏。「伙伴」管理形象和应用更新。「拓展」显示已安装插件和在线商店。有配置页或形象预览的插件在启用后出现在侧栏下方，停用会撤回这些入口。插件菜单和监控窗口可打开同一页。

启用坐姿插件后，用户可以主动开始监测。恢复上次运行需同时满足允许自动恢复、已有校准及摄像头已授权。停用会关闭监测与画中画窗口、释放摄像头和撤回提醒。气泡按插件及启用代次隔离，已停用的实例无法继续输出。

形象插件可以提供绘制回调。启用后加入「伙伴」页的形象选择，并立即切换；停用当前形象时回到小灰猫。纸船仅由回归检查注入，正式注册表只提供坐姿插件，小灰猫由宿主内建。
