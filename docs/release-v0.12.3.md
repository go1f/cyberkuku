# KukuSeat v0.12.3

- 应用图标与状态栏小灰猫均水平镜像翻转。应用图标保留圆角白底和原有留白。
- 状态栏改为原生模板图标，透明切口与下颌线保留，由 AppKit 按每块屏幕菜单栏背景及活动状态选择着色，不再固定白色。
- 所在显示器进入全屏后，小灰猫自动移至最近的左右边缘并收纳；退出后恢复全屏前的位置和展开状态，之前手动收纳的状态保持不变。自动收纳不写入用户位置偏好。
- 全屏期间只保留静止边缘入口，气泡与悬停探出暂停；双击仍可打开监控窗口。睡眠、锁屏和快速全屏往返会取消过期位移动画。
- 全屏边缘入口使用原生辅助全屏窗口行为，按显示器分别处理。

本次公开发布同时包含 0.11.0 之后已验收的本地改进：

- 桌宠缩小至原来的 3/5；Dock 图标使用圆角纯白底与适当透明留白，视觉尺寸与系统图标协调。
- 气泡优先出现在小灰猫中上方，箭头指向脑袋中心，多条提示保持避让。
- 支持原生 ⌘W 关闭窗口；双击小灰猫打开或聚焦监控窗口，单击静默与双击、拖动互不冲突。
- 拖到左右边缘后收纳，支持三种探头造型、靠近鼠标时临时浮出、单击固定展开；快速拖动不再产生鼠标偏移。
- 右侧自动转身；耳朵与藏脸造型保留原图轮廓。菜单明确显示小灰猫显隐状态，暂停监测时也可手动显示静止桌宠。

验证：111 项核心检查、46 项窗口与图标交互检查、5 项提醒检查通过。实机验收通过。

安装：Apple Silicon Mac 下载 DMG 后将 KukuSeat 拖到 Applications；已有版本可在应用内检查更新。继续使用固定的本地开发证书签名，更新信息经 Ed25519 签名。
