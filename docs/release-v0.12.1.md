# KukuSeat v0.12.1

- 菜单改为明确的“显示小灰猫／隐藏小灰猫／展开小灰猫”，使用原生勾选／混合状态，并固定显示一行当前状态：已显示、已隐藏、边缘收纳、全屏暂隐或静止显示。
- 修复暂停监测时点击显示只改变偏好、不显示小灰猫的问题。手动显示独立生效，暂停时为静止桌宠，不会自动启动摄像头；小灰猫状态行显示“已显示（静止）”，监测状态仍由菜单顶部独立显示。
- 显示操作展开收纳态，并优先找回到当前可用、非全屏的显示器；若所有显示器都在全屏，菜单明确显示暂隐状态，退出全屏后恢复。
- 手动隐藏、系统锁屏／睡眠、全屏暂隐分别处理，保留用户显示意图，解锁后恢复。显隐与收纳状态变化即时更新菜单，不新增或移除状态行。
