# KukuSeat v0.12.2

- 拖动改为按下时的固定抓取偏移加当前绝对鼠标坐标定位，抬起时使用最终坐标。快速往返、事件合并或中途窗口位置修正不再累计漂移；拖动中显示器变化不重新加载旧位置。
- 收纳后鼠标靠近约 12pt 时，小灰猫临时浮出；鼠标离开约 0.45 秒后退回原入口。刚拖到边缘时，先等鼠标移开再启用探出，避免收起后立刻又弹出。
- 临时探出时单击固定为常驻展开，不触发 30 秒静默；之后离开鼠标不再收纳，只有重新手动拖至边缘才会收起。双击仍打开监控窗口。
- 耳朵只显示原图双耳局部并增加露出面积；藏脸改用完整头部轮廓，保留额头、耳尖和下颌原线条，去掉头顶／下方的矩形裁切。
- 锁屏、全屏或隐藏会取消临时预览，恢复原收纳意图，不补播旧的探出动画。

验证：固定偏移的正负坐标序列、240 次快速反向及中途窗口修正、悬停往返、点击固定和中断恢复的合成／离屏原生检查。真实鼠标手感仍需实际试用确认。
